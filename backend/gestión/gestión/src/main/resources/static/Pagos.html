Generar cuotas del mes

Se genera una cuota por cada alumno activo inscripto en el curso. Si la cuota del período ya existe, se omite.

Registrar pago

Al confirmar, la cuota se marca como pagada y se registra automáticamente un ingreso con categoría Cuotas en Finanzas.

Eliminar cuota

Esta operación no se puede deshacer. Si la cuota ya fue pagada, también se eliminará el ingreso asociado en Finanzas.
